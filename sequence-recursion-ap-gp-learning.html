高中數學｜數列的規律、位置與總和

數列：從遞迴走到等差、等比與和公式

先看「下一項怎麼來」，再把規律改寫成「第 n 項在哪裡」。最後才使用前 n 項和與 1、2、3 次和公式。這樣公式不再是一串要硬背的符號。

遞迴式＋初始值 等差數列與等比數列 前 n 項和 Σk、Σk²、Σk³
先分清兩種問法 遞迴規律觀察器 等差、等比公式 一次二次三次和 自我檢查

0. 數列有兩個問題：下一項？第幾項？

數列像依序站在位置 1, 2, 3, … 的數。遞迴式描述「從前一項走到下一項的動作」；通項公式則直接告訴你「第 n 個位置的值」。

① 起點先知道 a₁ 是多少。
② 下一項規則例如每次加 3，或每次乘 2。
③ 位置與總和推得 aₙ，再算 Sₙ。
最重要的提醒：aₙ₊₁ = aₙ + 3 只有「走法」，還沒有起點。一定還要給 a₁，才會是唯一的一個數列。例如 a₁ = 2 與 a₁ = 100 都能每次加 3，但它們是不同數列。

1. 遞迴規律觀察器：先把數列「走」出來

切換兩種動作，調整起點和規則。觀察每一支箭頭旁的動作，再對照下方的第 n 項與前 n 項和。

2. 等差、等比：同樣是數列，改變的量不同

先辨認「相鄰兩項之差」是否固定；若不是，再檢查「相鄰兩項之比」是否固定。比值要注意分母不能是 0。

比較等差數列 AP等比數列 GP
遞迴式aₙ₊₁ = aₙ + daₙ₊₁ = r aₙ
固定的規律公差 d = aₙ₊₁ − aₙ公比 r = aₙ₊₁ / aₙ（aₙ ≠ 0）
通項aₙ = a₁ + (n−1)daₙ = a₁rⁿ⁻¹
前 n 項和Sₙ = n(a₁+aₙ)/2
也可寫成 n[2a₁+(n−1)d]/2		Sₙ = a₁(rⁿ−1)/(r−1)，r ≠ 1
若 r = 1，則 Sₙ = na₁。
代表例題｜等差

由遞迴式求第 10 項與前 10 項和

已知 a₁=5，aₙ₊₁=aₙ+3，求 a₁₀ 與 S₁₀。

  1. 每次加 3，所以這是等差數列，d=3。
  2. a₁₀=5+(10−1)×3=32。
  3. S₁₀=10(5+32)/2=185。
想法：先用通項找到最後一項，再用「項數 × 首尾平均」求和。
代表例題｜等比

由遞迴式求第 8 項與前 8 項和

已知 b₁=3，bₙ₊₁=2bₙ，求 b₈ 與 T₈。

  1. 每次乘 2，所以是等比數列，r=2。
  2. b₈=3×2⁷=384。
  3. T₈=3(2⁸−1)/(2−1)=765。
想法：第 8 項從第 1 項走了 7 次，所以指數是 8−1，不是 8。

3. 一次、二次、三次和：把前 n 個整數加起來

這三條不是「任意數列」都能直接套的公式，而是專門計算 1 到 n 的整數次方和。看到 Σ 時，先讀清楚每一項是 k、k² 還是 k³。

一次和

Σk

1+2+⋯+n = n(n+1)/2

把兩份階梯倒過來拼成長方形，面積是 n(n+1)，所以一份是它的一半。

二次和

Σk²

1²+2²+⋯+n² = n(n+1)(2n+1)/6

分母是 6；先因式分解或約分，再代入，計算比較穩。

三次和

Σk³

1³+2³+⋯+n³ = [n(n+1)/2]²

很好記：三次和 = 一次和的平方。

代入驗算小實驗

輸入 n，同時看三種和。可先用小的 n 手算，再用公式核對。

例題｜讀清楚平方在哪裡

求 1²+2²+⋯+10²

  1. 每一項都有平方，選二次和，不是一次和。
  2. 10×11×21 / 6。
  3. 先約分：10×11×21 / 6 = 5×11×7 = 385。
例題｜把一次和再平方

求 1³+2³+⋯+4³

  1. 先算一次和：1+2+3+4=4×5/2=10。
  2. 三次和就是一次和的平方。
  3. 1³+2³+3³+4³=10²=100。

4. 學生最常卡住的地方

  • 把第 n 項的指數寫成 n：等比從 a₁ 走到 aₙ，只走了 n−1 步，所以是 a₁rⁿ⁻¹。
  • 沒有先判斷是等差還是等比：看「差固定」或「比固定」，不能因為數字變大就直接當等比。
  • 把 Sₙ 當成第 n 項：aₙ 是一個位置上的數；Sₙ 是從第 1 項加到第 n 項的總和。
  • 看到 Σ 就直接套一次和：Σk²、Σk³ 的每一項不同，公式也不同。
  • 等比和公式忘了 r=1 的情況：此時分母 r−1 是 0，應改用 Sₙ=na₁。

5. 自我檢查：先選，再看理由

答錯時只會鎖住那個選項，請利用剩下的選項重新判斷；答對後才會顯示下一題。

基礎 由遞迴看出公差或公比，求第 n 項。

進階 由兩項反推 a₁,d,r，再求前 n 項和。

挑戰 把 Σk、Σk²、Σk³ 結合因式分解、數學歸納法或多項式題目。

自我檢查口訣：「有起點、看差比、數步數、分清項和。」

教師使用建議：一節課的節奏

可先讓學生操作規律觀察器：固定 a₁，只改 d 或 r。學生看到「每次加」與「每次乘」的成長差異後，再整理通項與和公式，會比直接抄公式更有意義。
