高中數學・矩陣 觀念釐清 × 解題選法

矩陣別憑直覺：常見錯誤與高次乘法五種方法

矩陣乘法不像一般數字：順序可能改變答案、非零矩陣相乘也可能變成零。遇到 An 時，先找結構再計算，往往比一直乘下去快得多。

先記一條規則 六個常見錯誤 五種高次方法 怎麼選方法 自我檢查

0. 先記一條規則：矩陣乘法是「接續動作」

把矩陣想成「把向量送進某台機器的規則」。在 AB 中，先做 B，再做 A；就像先穿襪子再穿鞋，反過來通常不是同一件事。

維度先行

若 A 是 m×n，B 是 n×p，才可以做 AB，結果是 m×p。內側數字要相同；不合就不是「算錯」，而是「根本不能算」。

(2×3)(3×4) 可以 → 結果是 2×4；　(2×3)(2×2) 不可以
乘法入口檢查：先看尺寸 → 再決定順序 → 最後才算每一格的「列乘欄」。這三步能擋掉很多失分。

1. 矩陣常見錯誤：每一個都用反例拆穿

反例的功能是：只要找到一個例子讓敘述失敗，就知道它不是每次都成立的規則。下列矩陣都可直接逐格驗算。

① 不可交換 ② 不可消去 ③ 零乘積 ④ 平方為零 ⑤ 平方為 I ⑥ 轉置與反矩陣
錯誤 ①

把矩陣當一般數：以為 AB = BA

錯！ 大多數矩陣乘法沒有交換律。

A = 1101 ， B = 1011
AB = 2111
BA = 1112
記法陷阱：寫 A2 時是 AA，並不代表你可以任意把不同矩陣對調。只有題目另外證明 AB=BA 時，才說它們可交換。
看第一格怎麼算：為什麼答案不同？
(AB)11 = 1×1 + 1×1 = 2；　(BA)11 = 1×1 + 0×1 = 1。

同樣用「第一列乘第一欄」，但第一列、第一欄換了來源，答案自然可能不同。

錯誤 ②

看到 AB = AC 就消掉 A，說 B = C

錯！ 左右消去律需要 A 可逆；若 A 不可逆，資訊可能被壓掉。

A = 1000 ， B = 1234 ， C = 129−1
AB = 1200 = AC，　但是 B ≠ C
什麼時候可以消？若 A−1 存在，才可在等式左邊同乘 A−1：
AB=AC ⇒ A−1AB=A−1AC ⇒ B=C。
用「機器」直覺理解

這個 A 只保留輸入的第一列，第二列不管原本是什麼都變成 0。因此不同的 B、C 經過 A 後，可能留下完全相同的結果。

錯誤 ③

以為 AB=O 就必有 A=O 或 B=O

錯！ 矩陣存在「零因子」：兩個非零矩陣相乘可以得到零矩陣。

A = 1000 ， B = 0010 → AB = 0000
考場判斷：AB=O 時，若已知 A 可逆，才可左乘 A−1 得 B=O。沒有「可逆」條件，不能下結論。
錯誤 ④

以為 A2=O 就必有 A=O

錯！ 有些非零矩陣平方後會完全消失，這類矩陣稱為冪零矩陣。

A = 0100 ， A2 = 0000 ，但 A ≠ O
逐格驗算 A²
A² = 0×0+1×00×1+1×00×0+0×00×1+0×0 = O。
錯誤 ⑤

以為 A2=I 就必有 A=I 或 A=−I

錯！ 反射、交換座標等動作，做兩次會回到原處，但做一次不一定沒變。

A = 0110 ， A2 = 1001 = I
圖像直覺：這個矩陣把 (x,y) 變成 (y,x)，也就是對直線 y=x 鏡射。鏡射兩次當然回到原點，所以平方是 I。
錯誤 ⑥

把乘積的轉置、反矩陣順序照抄

錯！ 兩者都要反轉順序。

轉置：
(AB)T = BTAT
不是 ATBT。
反矩陣（皆可逆時）：
(AB)−1 = B−1A−1
不是 A−1B−1。
最可靠的背法：要讓相鄰的東西消掉，就從最靠近的開始。例如 (AB)(B−1A−1)=A(BB−1)A−1=I。

2. 求 An 的五種常用方法

不是每一題都套同一招。先觀察矩陣的形狀、特殊關係或特徵值，再選最短的路。以下每一招都有「何時用」與可直接模仿的例子。

1

直接乘幾次，找出規律

適合對角矩陣、上下三角矩陣、全列同或全行同等一眼看得出結構的題目。

觀察重點：每次相乘後，哪些位置永遠是 0？哪些格子只是在乘固定倍率？
D = 200−3 → Dn = 2n00(−3)n
  1. 先算 D²：對角線變成 2²、(−3)²，其他位置仍為 0。
  2. 再看 D³，發現每個對角元素各自連乘。
  3. 寫出 Dn；不要把對角元素相加或互相交叉相乘。
再看一個上三角矩陣的規律
U = 2102，計算後可猜到 Un = 2nn·2n−102n。

這題也能改用方法 2；實戰時「看出規律」和「二項式」常互相支援。

2

拆成 I + B，使用二項式定理

當矩陣可寫成「純量倍的 I 加上好處理的矩陣」，而且 B²、B³… 有簡單規律時特別快。

關鍵理由：I 與任何同階矩陣都可交換，所以可合法使用二項式展開。
A = 3103 = 3I + N，N = 0100，N² = O
An = (3I+N)n = 3nI + n·3n−1N
= 3nn·3n−103n
為什麼只剩兩項？二項式裡所有含 N² 的項都等於 0；例如 N³=N²N=O。
使用二項式前的安全檢查

一般矩陣 (X+Y)² 是 X²+XY+YX+Y²，不能直接寫成 X²+2XY+Y²。只有確認 XY=YX 時，才可合併中間兩項。這一題因為其中一個是 3I，所以安全。

3

Cayley–Hamilton 定理：把高次降回低次

先由特徵多項式得到矩陣滿足的關係式，再把 A²、A³… 不斷化成 I 與 A 的組合。

適合：二階矩陣尤其好用；算出特徵值後，也能順便判斷能否對角化。
A = 1110，特徵多項式 f(λ)=λ²−λ−1
f(A)=A²−A−I=O　⇒　A²=A+I
  1. A³=A·A²=A(A+I)=A²+A=2A+I
  2. A⁴=A(2A+I)=2A²+A=3A+2I
  3. A⁵=A(3A+2I)=3A²+2A=5A+3I
看見遞迴：因為 A²=A+I，後面係數會出現費波那契型的遞迴。高次不再需要一格一格硬乘。
4

對角化：A=P−1DP

若有足夠的線性獨立特徵向量，可把難算的 A 變成好算的對角矩陣 D。

口訣：先「換座標」到特徵向量的世界，中間只算對角線次方，最後再換回來。
A = 11−24，P = 2−1−11，PAP−1 = D = 2003
An = P−1DnP = P−12n003nP
這題的完整答案與順序陷阱
An = 2n+1−3n3n−2n2n+1−2·3n2·3n−2n

小心：本例寫的是 D=PAP−1，因此要解出 A=P−1DP，高次後仍是 P−1DnP。不要把 P 與 P−1 的位置顛倒。

5

辨認幾何變換：旋轉、鏡射、伸縮、推移

有些矩陣本來就是平面上的動作；找「幾次後回到原狀」或「角度累加」最快。

適合：題目出現 cosθ、sinθ，或矩陣長得像旋轉、鏡射、伸縮、推移時。
旋轉 Rθ
Rθn=Rnθ
鏡射 S
S²=I
伸縮 kI
(kI)n=knI
推移 T
T=1c01 ⇒ Tn=1nc01
R = 0−110（逆時針轉 90°） → R²=−I，R⁴=I → R2026=R²=−I
餘數的用處：碰到 R2026 不要乘 2026 次；因為每 4 次重複，只要算 2026÷4 的餘數 2。

3. 考場上怎麼選方法？

第一眼：它是對角、三角、全列同或週期型嗎？→ 先試方法 1 或 5。
↓
第二眼：能寫成 rI+N，而 N²=O 或 N²=N 嗎？→ 用方法 2。
↓
第三眼：二階矩陣的特徵多項式好算嗎？→ 用方法 3把次方壓低。
↓
第四眼：有兩個不同特徵值／足夠特徵向量嗎？→ 用方法 4對角化。

老師可直接這樣帶

  1. 先讓學生算錯誤①的 AB、BA，感受「順序真的有差」。
  2. 再展示錯誤③，追問：「非零乘非零為什麼會是零？」
  3. 給一題 R2026，要求先說理由、再寫答案。
  4. 最後比較：同一個上三角矩陣可用觀察或二項式，但哪一種寫法最短？

五種方法的一句話總整理

方法找什麼特徵核心動作
1. 直接找規律0 的位置固定、對角或三角結構算前 2～3 次，歸納每格的變化
2. 二項式rI+N，且 N 的次方簡單確認可交換，展開後消去高次項
3. Cayley–Hamilton特徵多項式容易求用 f(A)=O 將高次降階
4. 對角化有足夠特徵向量把 A 換成對角矩陣 D
5. 幾何變換旋轉、鏡射、伸縮、推移利用週期、角度累加或固定形狀

4. 自我檢查：先選方法，再看理由

答錯也沒關係；先把理由讀懂，再回到上方找對應方法。這比只背答案更能避免下次選錯工具。
