一、國中版：指數是乘法的簡寫

國中基礎
先看意思

34 不是 3×4，而是把 3 連乘四次：

34 = 3 × 3 × 3 × 3 = 81

底數是 3；指數是 4。指數回答的是「這個底數連乘幾次」。

生活直覺

若一張紙每次都對折，厚度會每次變成 2 倍。對折 5 次後，是原來的 25 倍，而不是 2×5 倍。

「每次乘同一個數」就是指數最常出現的情境。

先判斷括號

(-2)4 = 16，因為負的 2 連乘四次。

-24 = -(24) = -16，因為次方只算 2；負號在外面。

二、國中版：同底數的三個基本公式

公式不是憑空背的：先把每個次方展開，就能看出連乘的個數如何改變。以下先以底數 a ≠ 0、整數指數為主。

相乘：指數相加
am × an = am+n

例：23×24 = 27。三個 2 再接四個 2，一共有七個 2。

相除：指數相減
am ÷ an = am−n

例：57÷52 = 55。分子、分母相同的 5 可以約掉兩組。

再乘一次方：指數相乘
(am)n = amn

例：(32)4 = 38。每一組有兩個 3，一共四組，所以有 2×4 個 3。

最常錯： am + an 不能合併成 am+n。例如 22+23 = 4+8=12，不是 25=32。只有「相乘／相除」才可用上面的指數規則。

三、國中版：科學記號讓大數、小數一眼看出大小

標準形式

科學記號寫成：

a × 10n，其中 1 ≤ a < 10

前面的 a 只能有一個整數位。例如 34.2×105 還要整理成 3.42×106。

大於 1 的數

把小數點往左移到第一個非零數字後面；移了幾位，指數就是正幾。

342 000 000 = 3.42 × 108

小數點從最後移到 3 後面，共向左移 8 位。

介於 0 與 1 的數

把小數點往右移到第一個非零數字後面；移了幾位，指數就是負幾。

0.000052 = 5.2 × 10−5

小數點向右移 5 位，所以是 10−5。

例題：把科學記號還原

8.15×105 要把小數點向右移 5 位。

= 815 000

例題：先估大小再檢查

6.7×10−3 一定比 1 小，結果應是小數。

= 0.0067

檢查口訣：數大於 1，科學記號的 10 次方通常是正指數；數介於 0 和 1，通常是負指數。若寫完後 a 不是 1 到 10 之間，表示還沒有標準化。

四、高中版：分數次方把「開根號」寫成指數

高中進階

分母告訴我們要開幾次根號，分子告訴我們再做幾次方。先在實數範圍下討論，遇到偶次根號尤其要先看定義域。

核心翻譯
am/n = (ⁿ√a)m = ⁿ√(am)

例：163/4 = (⁴√16)3 = 23 = 8。

負指數仍是倒數
a−m/n = 1 / am/n

例：81−3/4 = 1/(⁴√81)3 = 1/27。

定義域先行

若分母化簡後是偶數，例如 x1/2，實數範圍必須 x ≥ 0。

若分母是奇數，例如 x1/3，負數也可以代入。

例題：分數次方方程式

解 x2/3 = 4。

令 t=∛x，則 t2=4，所以 t=±2。

x = t3 = ±8

易錯提醒：不要漏掉負解

因為 (-8)2/3=(∛(-8))2=(-2)2=4，所以只寫 x=8 不完整。

五、高中版：把複雜指數式換成一個正變數

遇到 a2x、ax 同時出現時，不要急著取對數；先令 t=ax。因為指數函數值永遠正，所以還要保留 t>0。

1

看出同一個底數

22x = (2x)2，這使原式能變成二次式。

2

代換並先解 t

令 t=2x>0。例如 22x−5·2x+4=0 變為 t2−5t+4=0。

3

篩掉不合 t>0 的值，再換回 x

(t−1)(t−4)=0，得 t=1,4；所以 2x=1,4，答案是 x=0,2。

最常錯：代換後得到 t=-2 時，不能直接回推 ax=-2；實數範圍的正底數指數函數不會等於負數。

六、高中版：指數不等式先判斷底數

底數大於 1：方向不變
a > 1：au > av ⇔ u > v

例：3x+1 ≥ 9x−1，先寫成 3x+1 ≥ 32x−2，所以 x+1 ≥ 2x−2，得 x≤3。

底數介於 0 與 1：方向反轉
0 < a < 1：au < av ⇔ u > v

例：(1/2)2x−1 < (1/2)x+2，指數比較時要反向：2x−1 > x+2，得 x>3。

代換型不等式

22x−5·2x+4>0，令 t=2x>0，變成 (t−1)(t−4)>0。

解得 0<t<1 或 t>4，所以 x<0 或 x>2。

七、高中版：用對數反推科學記號中的指數

當數字不是剛好等於 10n 時，對數會補上「介於兩個整數次方之間」的那一小段。這正是用科學記號判斷數量級的關鍵。

從科學記號反推 x

若 10x = c×10n，且 1≤c<10，兩邊取常用對數：

x = log(c×10n) = log c + n

例：10x=6.02×1023，則 x=23+log 6.02≈23.7796。

從 x 寫回科學記號

若 x=−5.347，整數部分要取下整數 −6：

10−5.347 = 100.653 × 10−6 ≈ 4.50×10−6

負數時不能直接把小數點「截掉」成 −5；必須用下整數，才能讓前面的係數落在 1 到 10 之間。

一般底數的反推

若 ax=N，且 a>0、a≠1、N>0，則：

x = logaN = log N / log a

例如 2x=1000，可以用 x=log 1000/log 2 求近似值。

小工具 A：科學記號 → 10 的指數

輸入 c×10n，計算 log10(c×10n)。

例如：6.02 × 1023 對應的 x 約為 23.7796。

小工具 B：10 的指數 → 科學記號

輸入 x，將 10x 寫成標準科學記號。

例如：10−5.347 ≈ 4.50 × 10−6。
計算機提醒：本頁的 log 指常用對數（底數 10）。若計算機畫面顯示 ln，那是自然對數；要算 10x 的反推時，優先使用 log。

八、高中挑戰：負次方與複雜次方計算

高中挑戰

這一版的重點不是把指數湊成很大的數，而是能在負次方、負號、括號和多個底數混在一起時，仍然穩定地看出結構。所有含負次方的底數都必須不為 0。

負次方不是負數
a−n = 1 / an（a ≠ 0）

2−3 = 1/23 = 1/8。負號告訴我們「取倒數」，不是讓答案自動變成負數。

例如 (−2)−3=−1/8，答案為負是因為底數本來是負數且次方為奇數。

由相除公式看來源
a3 / a5 = a3−5 = a−2 = 1/a2

負次方其實是「分母的同底數比上分子的同底數還多」；把多出的因數留在分母，就自然得到倒數。

括號決定負號算到哪裡

(−2)−4=1/16，底數是 −2。

−2−4=−(2−4)=−1/16，外面的負號沒有被次方算進去。

遇到負數底數，先圈出底數範圍，再開始算。

複雜次方計算的四步驟

1

先保留括號，辨認每個底數

(2−2)−3 的底數是整個 2−2；不能把兩個負號先消掉就停下來。

2

把可改寫的數化成同一底數

例如 4=22、8=23、9=32、27=33；同底數後才可加減指數。

3

由內而外處理「次方的次方」

(am)n=amn，連負號也要一起乘：(2−2)−3=2(−2)(−3)=26。

4

最後才把負指數搬成倒數

先合併同底數可減少分數運算；最後把 a−k 改寫為 1/ak，答案通常更清楚。

例題 A：巢狀負次方

化簡 (2−2)−3 × 4−1。

=26×(22)−1=26×2−2=24

= 16

例題 B：含字母的複雜化簡

化簡 (a−2b3)−2 ÷ (ab−1)（a,b≠0）。

=a4b−6 ÷ (ab−1)=a4−1b−6−(−1)=a3b−5

= a3 / b5

三個高頻失誤： (a+b)−2 不能寫成 a−2+b−2； (ab)−2 才能寫成 a−2b−2； 而 a−2+a−3 仍是加法，必須先通分或提出公因式，不能直接把指數相加。
