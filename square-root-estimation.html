0. 所有估計法都在做同一件事：比較平方

觀念起點

如果 a² < N < b²，而 a、b 都是正數，便能確定 a < √N < b。根號不是神祕的新運算：它問的是「哪一個正數平方後會變成 N？」

先背附近平方數

例：√20 在哪裡？

4² = 16 < 20 < 25 = 5²

所以 4 < √20 < 5。這是後面所有小數估計的起點。

平方越大，根號越大

比較不用真的開根號

√37 < 7，因為 37 < 49 = 7²

比較 √37 和整數時，先把整數平方；這比直接猜答案可靠。

常見錯誤：只看被開方數的十位數

錯誤想法：20 介於 4 和 5，所以 √20 也許介於 2 和 3。
改正：要比較的是 平方：4²、5²，不是 4、5 本身。

1. 基本二分法：每次把答案範圍切一半

基礎

已知根號在兩個數之間，就取正中間的數 m，只要算 m²。若 m² < N，表示 m 太小，左端往右移；反之右端往左移。

手算示範：估 √20

  1. 已知 4 < √20 < 5。
  2. 中點是 4.5，而 4.5² = 20.25 > 20，所以 √20 < 4.5。
  3. 新範圍為 4 < √20 < 4.5；中點 4.25² = 18.0625 < 20。
  4. 所以再縮成 4.25 < √20 < 4.5。每按一次，範圍就減半。

按一次，做一次二分判斷

下界 L4
中點 m4.5
上界 U5
先按「下一次二分」，檢查中點的平方。
    二分法的小提醒：中點平方「小於」目標時，根號在中點右邊；中點平方「大於」目標時，根號在中點左邊。不要把左右方向顛倒。

    2. 十分法：先選到 0.1，再選到 0.01

    基礎

    十分法不是亂猜小數，而是在已知下界上，一格一格試 0.1。找出「平方仍不超過 N」的最大數；接著把步長改成 0.01，做完全同樣的事。

    例：√20 的十分位

    4.4² = 19.36 < 20；4.5² = 20.25 > 20

    因此 4.4 < √20 < 4.5，十分位是 4。接著試 4.41、4.42、…，就能找百分位。

    這是「由粗到細」的試位；直式開根號其實也在做逐位選數字，只是把試算整理得更省力。

    點選你要試的下一位

    先找最大整數下界，再選十分位。

    常見錯誤：看到 4.5² > 20，答案不是 4.5；應回到前一個仍不超過 20 的數 4.4。若要寫估計範圍，就要同時寫出上下兩端。

    3. 用乘法公式快速估計：把「差多少」分給 2a

    進階

    當 N 靠近一個完全平方數 a² 時，設 √N = a + x。展開平方後，根號的變化量 x 就能快速估出來。

    從乘法公式推出估計式

    (a + x)² = a² + 2ax + x²

    令 N = a² + d，則 d = 2ax + x²。

    若 x 很小，x² 更小，先忽略它：

    x ≈ d / (2a)，所以 √N ≈ a + (N − a²) / (2a)

    例如 √50 靠近 7² = 49：√50 ≈ 7 + 1/14 ≈ 7.0714。

    乘法公式估計器

    更快驗算候選小數

    要驗 7.07 是否接近 √50，不要硬做 7.07 × 7.07：

    (7 + 0.07)² = 49 + 2×7×0.07 + 0.07² = 49.9849

    因為仍小於 50，故 7.07 < √50。

    估計式不是精確等號

    不能把 ≈ 寫成 =。由於 x² 被先省略，這是近似值。實際上 a + d/(2a) 的平方會比 N 多出一個正的 x²，所以這個一次估計通常略偏大。

    4. 直式開根號：每按一次，只做一個動作

    逐步算法

    直式法把被開方數從小數點向左右，每兩位分一組。每一組決定根號的一位數。先用 √529 看清楚完整的整數流程；再選 √12.25，特別觀察小數點何時要對齊寫進答案。

    準備開始
    先把數字每兩位分成一組

    例如 529 要分成 5 ｜ 29。第一組先找平方數；接著依序「相減、帶下、根號加倍、試填、相減」。

    先記住兩個核心：第一位找 x²；後續先把已得根號加倍，在右邊留一格，再用同一個試填數字填入空格並相乘。
    根號答案 ＿
    05′29
    最常卡住的地方：看到已得根號是 3，先寫 3×2=6，再留一格成為 6＿；試 5 時，空格與乘數都填 5，得到 65×5=325。因此不是只算 6×5。每次帶下兩位，正是這個直式規則成立的原因。
