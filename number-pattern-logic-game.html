老師帶領與學生自學：怎麼解規律題？
  1. 先分類：是單一路徑數列、交錯兩條數列、表格橫列規則，還是圖形中相鄰數的關係？
  2. 寫出動作：不要只說「有規律」，而要說「每次加 3」、「乘 2 再加 1」或「上方等於下方兩數相加」。
  3. 全體驗證：至少用三組已知資料檢查。只符合前兩項的規則通常不可靠。
  4. 最後填空：填完再倒回去驗算，並說出為什麼不是別的數字。

常見錯誤：把相鄰兩項與隔一項混在一起；看到大數字便急著乘法；或只驗證一次就下結論。遇到交錯題，先把奇數位置與偶數位置分開看。
