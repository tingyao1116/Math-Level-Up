高一・多項式除法 長除法：乘回後相減 綜合除法：乘後相加

多項式除法：一題看懂兩種算法

先固定一題，並排看長除法與綜合除法。接著把結果濃縮成除法原理的三種型式，再用同一個原理整理商式、餘式在四種倍數變化下怎麼改變。

一題對照 除法原理三型 四種倍數變化 商與餘式例題 餘式與因式定理 二次與高次不等式

1. 固定同一題：兩種方法到底差在哪裡？

例題：(2x3−3x2−11x+6) ÷ (x−3)。答案都是 2x2+3x−2，餘式都是 0；差別只在中間的書寫與運算動作。

最常見錯誤相減時沒有整個括號變號。x+3=x−(−3)，應放 −3，不是 3。
補一個必要限制：若除式是 ax+b=a(x−r) 且 a≠1，綜合除法先得到的是「除以 x−r」的商，最後還要再除以 a。例如除以 2x−6=2(x−3) 時，上表的商 2x2+3x−2 還要除以 2。

2. 除法原理：同一件事的三種型式

設 A 是被除式、B 是除式、Q 是商式、R 是餘式，且 deg R < deg B。

原型

先記住角色

A = BQ + R

被除式 = 除式 × 商式 + 餘式。

整除型

把餘式移到左邊

A − R = BQ

B 整除 A−R。當 R=0 時，才進一步得到 A=BQ，也就是 B 整除 A。

分數型

兩邊同除以 B

AB = Q + RB

商式是整式部分，餘式留下真分式部分。

3. 先看餘式，再看商式：四種倍數變化

從原型 A=BQ+R 出發。這裡 m,n 是非零常數；多項式的商式允許分數係數。

先抓餘式：在這四種比較裡，除式放大 n 倍不會改變餘式；被除式放大 m 倍，餘式才跟著放大 m 倍。所以餘式只要看「被除式有沒有乘 m」。
再看商式：商式就是「被除式 ÷ 除式」的結果；被除式乘 m，商乘 m；除式乘 n，商除以 n。
四種情況由原型改寫商式餘式
被 ÷ 除A = BQ + RQR
被 ÷ n除A = (nB)Qn + RQ/nR
m被 ÷ 除mA = B(mQ) + mRmQmR
m被 ÷ n除mA = (nB)mQn + mRmQ/nmR

糖果例子：1 包有 1003 顆，原本分給 100 人

1003 = 100×10 + 3

原本每人 10 顆，剩 3 顆。取 m=3（3 包糖果）、n=2（人數變 2 倍），剛好可以直接對照上表。

情況實際分法每人分到（商）剩下（餘）
被 ÷ 除1003 = 100×10 + 3103
被 ÷ 2除1003 = 200×5 + 353
3被 ÷ 除3009 = 100×30 + 9309
3被 ÷ 2除3009 = 200×15 + 9159
表格的讀法：從第一列到第二列，只把人數乘 2，所以商 10 變 5、餘數仍是 3；從第一列到第三列，只把糖果乘 3，所以商 10 變 30、餘數 3 也變 9。第四列同時做兩件事：10×3÷2=15，而餘數只看被除式的 3 倍，所以是 3×3=9。

4. 除法原理例題：不必每次都做長除法

以下題目都從 A=BQ+R 出發。真正關鍵是：餘式一定要比除式次數低；遇到一次式時，可以直接代入它的根。

例題 1：先檢查餘式次數

同一個式子，換除式後商、餘可能要再整理

已知

F(x)=(x3−2x+4)(x2−x+2)+(x2+3)
  1. F(x) 除以 x3−2x+4：商是 x2−x+2，餘式是 x2+3。
  2. 改除以 x2−x+2 時，原本的 x2+3 次數太高，不能直接當餘式。
  3. x2+3=(x2−x+2)+(x+1)，所以要再把前一項併入商。
答案：除以 x2−x+2 的商為 x3−2x+5，餘式為 x+1。
例題 2：餘式乘上 x²，還要再降次

先用除式把高次項換掉

已知 f(x) 除以 D(x)=x2−2x+2 的餘式為 x+4，求 x2f(x) 除以 D 的餘式。

  1. 由 x2−2x+2=0 的餘式關係，得到 x2≡2x−2（模 D）。
  2. x2f(x)≡x2(x+4)≡(2x−2)(x+4)。
  3. (2x−2)(x+4)=2x2+6x−8≡2(2x−2)+6x−8=10x−12。
答案：餘式是 10x−12。
例題 3：一次式除法，用代根最快

代入 x=1，把複合式直接變成數字

已知 f(x) 除以 x−1 的餘式為 2，g(x) 除以 x2+x−2 的餘式為 3x−5。求 x2[f(x)+1][g(x)−2] 除以 x−1 的餘式。

  1. 除以 x−1，只要代 x=1。
  2. f(1)=2；又 x2+x−2=(x−1)(x+2)，所以 g(1)=3(1)−5=−2。
  3. 12[2+1][−2−2]=−12。
答案：餘式是 −12。
例題 4：ax−b 與 x−b/a

先把同一個根寫出來

已知 f(x) 除以 3x−2 的餘式為 r。求 (2x+3)f(x) 除以 x−2/3 的餘式。

  1. 3x−2=3(x−2/3)，兩個除式的根都是 x=2/3。
  2. 因此 f(2/3)=r。
  3. 代入：(2·2/3+3)f(2/3)=(4/3+3)r=13r/3。
答案：餘式是 13r/3。
自我檢查：商與餘式的變化

已知 f(x) 除以 2x+1 的商為 Q(x)、餘式為 r。

1. f(x) 除以 x+1/2 的商、餘式各是什麼？
2. xf(x) 除以 2x+1 的餘式是什麼？

答案：1. 因 2x+1=2(x+1/2)，商為 2Q(x)，餘式為 r。
2. 代根 x=−1/2，餘式為 −r/2。

5. 最後收束：餘式定理與因式定理

餘式定理

若 P(x) 除以 x−c 的餘式是 R，則

P(x)=(x−c)Q(x)+R

令 x=c，第一項變 0，所以 P(c)=R。

因式定理

餘式為 0 就是整除，因此

P(c)=0 ⇔ (x−c) 是 P(x) 的因式

注意：因式是 x+3 時，要代入的是 c=−3。

回到本頁例題：P(x)=2x3−3x2−11x+6，除以 x−3 的餘式是 0，所以 P(3)=0，因此 x−3 是 P(x) 的因式。

6. 不等式：先用二次函數定規則，再推進到高次

解不等式不是只找根，而是判斷每個區間的正負。二次式可以用判別式快速分類；高次式則把根排在數線上，做號誌表。

二次不等式的固定流程
  1. 先移項，寫成 f(x)=ax2+bx+c 與 0 比較。
  2. 先看 a：若 a<0，可整式乘 −1，不等號要反向，化成開口向上的情形。
  3. 計算 Δ=b2−4ac，再依 Δ>0、Δ=0、Δ<0 寫解集。
先統一成 a>0 的閱讀法：本節三張表都先假設 a>0。若原式 a<0，先乘 −1 並把 > 與 <（≥ 與 ≤）互換，再照同一張表讀。這樣不用硬背兩套答案。
Δ > 0：兩個相異實根

設 α<β，且 a>0

+α−β+
f(x)>0x<α 或 x>β
f(x)≥0x≤α 或 x≥β
f(x)<0α<x<β
f(x)≤0α≤x≤β

口訣：開口向上時「外正內負」；有等號就把根收進答案。

Δ = 0：一個重根

設重根為 r，且 a>0

f(x)=a(x−r)2
f(x)>0x≠r
f(x)≥0x∈ℝ
f(x)<0∅
f(x)≤0x=r

圖形只碰到 x 軸，不會穿越；所以除了 r 以外都在 x 軸上方。

Δ < 0：沒有實根

且 a>0

f(x)>0（對所有實數）
f(x)>0x∈ℝ
f(x)≥0x∈ℝ
f(x)<0∅
f(x)≤0∅

沒有實根只代表「不碰 x 軸」；還要看 a。此處 a>0，所以整條拋物線都在上方。

三個二次不等式：把答案寫成解集

Δ > 0

x2−5x+6≥0

根為 2、3；開口向上，外正內負。

答案：x≤2 或 x≥3
Δ = 0

x2−4x+4>0

(x−2)2>0，只有 x=2 會等於 0。

答案：x≠2
Δ < 0

x2+2x+5≤0

Δ = 4−20<0，且開口向上，永遠為正。

答案：∅
常見錯誤：看到 Δ<0 就立刻寫「無解」。不對；要先問題目是在解 f(x)>0 還是 f(x)<0，也要看開口方向。
進階：高次不等式的號誌表

不必展開，先因式分解、排根、看重數

1. 因式分解把式子寫成各一次因式的乘積。
2. 根排數線由小到大標出所有實根。
3. 看重數奇數重根：穿越就變號；偶數重根：碰到但不變號。
4. 選區間從最高次係數判斷最右邊正負，再依題目的 >、≥、<、≤ 收集區間與根。

例題：解 (x+3)(x+1)2(x−2)≥0。

根依序是 −3、−1、2；其中 −1 是偶數重根，左右兩邊的符號一樣。

x 的位置(−∞,−3)−3(−3,−1)−1(−1,2)2(2,∞)
乘積正負+0−0−0+
答案：x≤−3，或 x=−1，或 x≥2。
注意 −1 雖然左右都是負，但題目是 ≥0，所以它本身的 0 必須單獨收進來。
挑戰練習：自己做一次號誌表

解 (x+2)2(x−1)3(x−4)<0。

提示：根是 −2（偶數重根）、1（奇數重根）、4（奇數重根）；最高次係數為正，先從最右邊的正號開始。

答案：1<x<4。
