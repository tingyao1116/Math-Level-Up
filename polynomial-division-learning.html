1. 先抓住：不是「減法變加法」，而是把反向先放進去了

多項式長除法：每輪都要消掉最高次項

先用商式的一項乘回除式，再把這個乘積從目前式子減掉。因為我們要讓最高次項相消，才能往下一次。

目前式 −（本輪商式 × 除式）

這和數字長除法完全同一個精神：估商、乘回、相減、再落下一項。

綜合除法：只限除式為 x − r

除式已寫成 x − r，長除法中本來要「減掉負的部分」的反向訊息，濃縮成乘 r 後相加。

下一格 = 原係數 + r × 前一格結果

若除式是 x + 2，要放的不是 2，而是 r = −2：因為 x + 2 = x − (−2)。

老師可直接這樣說

1長除法：我把「多出來的那一塊」乘回去，再減掉它。
2綜合除法：我不寫字母，只追蹤係數；−r 的反向效果已經改成「乘 r 後加」。
3先檢查除式：一定先改成 x−r，否則最容易把 r 的正負號放錯。
最常犯錯：看到 x+3 就把 3 放進綜合除法。錯！要寫成 x−(−3)，所以放 −3。

2. 同一題逐步對照：長除法的「減」與綜合除法的「加」

互動工作台

係數從最高次到常數項輸入；例如 2x³−3x²−11x+6 輸入 2,-3,-11,6。除式輸入為 ax+b。

不可漏寫 0，例如 x³−4x+1 要輸入 1,0,-4,1。

Ａ．長除法：乘回以後要減

Ｂ．綜合除法：帶入 r，乘後相加

綜合除法最重要的限制：除式若是 ax+b，而 a≠1

先令 r=−b/a，因此 ax+b=a(x−r)。綜合除法實際上先完成的是「除以 x−r」；它吐出的商式還要再除以 a，才是原來除以 ax+b 的真正商式。

P(x) = (x−r)S(x)+R = (ax+b)S(x)a+R
請特別看「÷ (2x−6)」預設：綜合除法得到 S(x)=2x²+3x−2；真正的商是 Q(x)=S(x)/2=x²+(3/2)x−1，不是直接抄 S(x)。

兩種方法的工作分工

比較長除法綜合除法
可用的除式任何非零多項式最直接只用在 x−r；ax+b 要補除以 a
板書動作估商 → 乘回 → 相減落下 → 乘 r → 相加
優點結構完整，不怕二次以上除式一次除式時快，容易看出餘數與因數
最容易錯相減時沒有整個括號一起變號x+c 放成 c；或忘記 a≠1 還要除 a

3. 從數字長除法、短除法，連到係數的「乘後相加」

數字長除法

1003 ÷ 10 = 100 … 3

也是：估一位商、乘回、相減、落下一位。它和多項式長除法的流程完全同型。

1003 = 10×100 + 3

Horner／綜合除法式讀數

把 1003 看成 1·10³+0·10²+0·10+3：

(((1×10+0)×10+0)×10+3)=1003

這正是「落下、乘 10、相加」；係數像各個位數。

反覆短除法換進位

要把十進位數換成 b 進位，可反覆除以 b；餘數由下往上讀。

它和綜合除法都有規律表格，但目的不同：一個找新進位的各位數，一個做多項式除法／代值。

動手看「反覆短除法」與「Horner 讀值」

把數字當成 b 進位的位數來讀

例如在十進位，1003 的位數為 1,0,0,3；從左到右做「×10 再 + 下一位」。

關鍵區分：若要把 1003 當作 b 進位表示法，它的每一位必須小於 b。Horner 是「由位數組回數值」；反覆短除法是「由數值拆出位數」。

4. 除法原理：一般型、整除型、分數型

一般型

先記原始身分

P(x)=D(x)Q(x)+R(x)

deg R < deg D；若餘式是 0，代表剛好除盡。

整除型

餘式為 0 的特例

P(x)=D(x)Q(x)

此時說 D(x) 整除 P(x)，也說 D(x) 是 P(x) 的因式。

分數型

兩邊同除以除式

P(x)D(x)=Q(x)+R(x)D(x)

這就是分式化簡時「多項式部分 + 真分式部分」的來源。

5. 除法原理告訴我們：被除式、除式放大後，商與餘怎麼變？

先用 1 包糖果建立原型

1003 = 100×10 + 3

1 包有 1003 顆，分給 100 人：每人 10 顆，剩 3 顆。把這一行的角色換成 P=DQ+R，就可以直接推理，不必重新長除一次。

原來

1 包，100 人

1003=100×10+3

商 10，餘 3。

被除式 3 倍

3 包，100 人

3009=100×30+9

商與餘都變 3 倍。

除式 2 倍

1 包，200 人

1003=200×5+3

商變成一半，餘數仍是 3。

被除式變 m 倍

mP=D(mQ)+mR

因此：商變 m 倍，餘式也變 m 倍。

糖果例：3 包時，10 → 30，3 → 9。

除式變 n 倍

P=(nD)Qn+R

在多項式（允許分數係數）裡：商除以 n，餘式不變。

糖果例：100 人變 200 人，10 → 5，餘 3 不變。

重要界線：這裡談的是多項式除法，商可以有分數係數。若做「整數糖果」的普通除法，商通常要求是整數；當 Q 不能整除 n 時，要重新用整數除法解讀，餘數不一定保持原值。上面的 1003 與 200 人剛好沒有這個問題。

6. 餘式定理與因式定理：綜合除法最後一格的意義

餘式定理

若 P(x) 除以 x−c 的餘式是 R：

P(x)=(x−c)Q(x)+R

把 x=c 代入，前面一項會變 0，所以

P(c)=R

因此綜合除法最右下角，就是 P(c) 的值。

因式定理

餘式剛好等於 0 時：

P(c)=0 ⇔ (x−c) 是 P(x) 的因式

不是「看到 c 就有因式」；一定要真的代入後等於 0。

符號提醒：若因式是 x+4，它是 x−(−4)，所以要檢查的是 P(−4)。

7. 三題即時自我檢查

基礎：放哪個數？

除式是 x+4，綜合除法左邊要放？

進階：還差哪一步？

除以 3x−6，綜合除法得到 S(x)。真正商是？

挑戰：放大除式

P=DQ+R 中，改成除以 2D（多項式係數可分數），商與餘？

基礎練習

1. 用綜合除法計算 (x³−5x+6)÷(x−2)。
2. x³−5x+6 除以 x+2 的餘式是多少？先寫出要代入的數。

答案：1. 商 x²+2x−1，餘 4。2. 代 −2，餘 P(−2)=8。

進階練習

計算 (2x³−3x²−11x+6)÷(2x−6)，並說明為何不能直接把綜合除法的商抄下來。

答案：商 x²+(3/2)x−1，餘 0；因為綜合除法對應先除 x−3，還要除以首項係數 2。

挑戰練習

已知 P=DQ+R。求 3P 除以 2D 後的商與餘式（允許分數係數）。

答案：3P=(2D)(3Q/2)+3R，所以商是 3Q/2，餘式是 3R。
