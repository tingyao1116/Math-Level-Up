函數變換教學：聚焦 \(x \to x'\)、\(y \to y'\)

這頁把「平移、縮放、旋轉、鏡射」統整成可直接上課的對照。核心目標是讓學生知道：先看座標怎麼變，再回寫到新方程式。

一、先建立總觀念（老師板書建議）

原圖上點 \((x,y)\)，變換後變成 \((x',y')\)。

若原函數是 \(y=f(x)\)，可用「反推舊座標」寫新圖：找到 \(x,y\) 用 \(x',y'\) 表示，再代回 \(y=f(x)\)。

常錯提醒：學生最常把 \(y=f(x-h)\) 看成左移。其實是右移 \(h\)（因為要讓函數值出現在更大的 \(x\) 位置）。

三、座標規則快查

操作\(x,y \to x',y'\)新方程式（由 \(y=f(x)\) 出發）
x 平移 h\((x',y')=(x+h,y)\)\(y=f(x-h)\)
y 平移 k\((x',y')=(x,y+k)\)\(y=f(x)+k\)
x 縮放 \(s_x\) 倍\((x',y')=(s_xx,y),\,s_x>0\)\(y=f\!\left(\frac{x}{s_x}\right)\)
y 縮放 \(s_y\) 倍\((x',y')=(x,s_yy),\,s_y>0\)\(y=s_yf(x)\)

四、旋轉與鏡射

操作\(x,y \to x',y'\)方程式替換規則
關於 \(x\) 軸鏡射\((x',y')=(x,-y)\)\(y=-f(x)\)
關於 \(y\) 軸鏡射\((x',y')=(-x,y)\)\(y=f(-x)\)
關於原點鏡射\((x',y')=(-x,-y)\)\(y=-f(-x)\)
關於 \(y=x\) 鏡射\((x',y')=(y,x)\)互換 \(x,y\)：\(x=f(y)\)（可能不再是函數）
關於 \(y=-x\) 鏡射\((x',y')=(-y,-x)\)\(x=-f(-y)\)（可能不再是函數）
逆時針 \(90^\circ\) 旋轉\((x',y')=(-y,x)\)先用 \(x=y',\,y=-x'\) 代回原式
圓 \(x^2+y^2=r^2\) 對旋轉不變；拋物線、指數、對數旋轉後常不再是函數圖形（可能變成側開曲線）。對 \(y=x\)、\(y=-x\) 對稱時，定義域與值域會互換；原圖不是一對一函數時，結果通常不是 \(y=\cdots\) 的函數。

絕對值效果快記

寫法圖形效果最容易混淆處
\(y=f(|x|)\)右半部複製到左半部是「式子裡的 x」取絕對值，不是每個點的 x 座標直接取絕對值。
\(y=f(-|x|)\)左半部複製到右半部先看 \(-|x|\le 0\)，因此只保留原圖左半部。
\(y=|f(x)|\)下方圖形往上翻上半部不動；是「函數值 y」取絕對值。
\(y=-|f(x)|\)上方圖形往下翻下半部不動；最後整張圖都不會高於 x 軸。

五、正弦函數專題：從 \(y=a\sin(bx+c)+d\) 看懂伸縮與平移

先固定 \(b>0\)，並約定 \(-\pi\le c<\pi\)。這樣一張圖的「向右／向左位置」才會有唯一的 \(c\)；否則 \(c\) 加上整數倍 \(2\pi\)，其實仍是同一張圖，無法公平判分。

先讀外面：\(a,d\)

中線是 \(y=d\)；振幅是 \(|a|=\frac{\text{最高值}-\text{最低值}}2\)。從中線向右穿越時，若曲線先上升則 \(a>0\)，先下降則 \(a<0\)。

再讀裡面：\(b,c\)

週期 \(T=\frac{2\pi}{b}\)，所以 \(b=\frac{2\pi}{T}\)。先找曲線以「原本正弦的方向」穿過中線的位置 \(x=h\)，則 \(h=-\frac cb\)，也就是 \(c=-bh\)。

路線 A：先縮放，再平移

路線 B：先平移，再縮放

範例圖：中線、週期與五個標記點

藍色虛線是中線；A 到 B 是一個週期。A、P、M、Q、B 對應一個週期中的五個關鍵位置，先由它們讀出中線、振幅與週期。

最常錯：\(f(bx+c)\) 的平移量不是直接看 \(-c\)。若先做「水平縮放」，最後真正看見的平移量是 \(h=-\frac cb\)；例如 \(\sin(2x-\pi)=\sin\bigl(2(x-\frac\pi2)\bigr)\)，是右移 \(\frac\pi2\)，不是右移 \(\pi\)。

讀圖練習：判斷 \(a,b,c,d\)

請由圖形填入 \(y=a\sin(bx+c)+d\)。本題都採 \(b>0\)、\(-\pi\le c<\pi\)，且 \(c\) 請寫成 \(\pi\) 的倍數。

答對 0 / 0 題

圖上標有中線、整數／分數 \(\pi\) 刻度，以及一個週期的 A、P、M、Q、B。先讀 \(d,a\)，再讀 \(T,b\)，最後由 A 的位置求 \(c=-bh\)。

\(a,b,d\) 可填整數或分母為個位數的分數；\(c\) 可填 \(\pi/2\)、\(-2\pi/3\) 等。

正弦、餘弦疊合：\(A\sin x+B\cos x\) 的最大值與最小值

把兩個波合成一個振幅固定的正弦波；先找振幅 \(R\)，再看角度範圍是否允許函數走到最高或最低點。

核心合成公式

\[A\sin x+B\cos x=R\sin(x+\varphi)\]

當 \(A,B\) 不同時為 \(0\) 時，\(R=\sqrt{A^2+B^2}>0\)，且 \(\cos\varphi=\frac{A}{R}\)、\(\sin\varphi=\frac{B}{R}\)。

簡易版：沒有角度範圍

因為 \(-1\le\sin(x+\varphi)\le1\)，所以最大值是 \(R\)，最小值是 \(-R\)。

例：\(2\sin x-2\cos x=2\sqrt2\sin(x-\frac\pi4)\)，最大值 \(2\sqrt2\)，最小值 \(-2\sqrt2\)。

進階版的固定流程：先寫成 \(R\sin(x+\varphi)\)，列出區間內可能使 \(\sin(x+\varphi)=1\) 或 \(-1\) 的角，再把「區間兩端」一併代入比較。區間有限時，答案不一定是 \(\pm R\)。
常見錯誤：只算出 \(R\) 就直接寫最大、最小值；這只在 \(x\) 沒有限制時成立。進階題不可把 \(\varphi\) 或三角值改成小數，應保留 \(\pi\)、根號與分數。

分層精確練習

請選出函數的最大值與最小值；所有答案都保留根號，不使用近似值。

答對 0 / 0 題

六、可直接上課的例題

例1（二次）：\(y=x^2\) 右移 3、上移 2，得到 \(y=(x-3)^2+2\)。

例2（圓）：\(x^2+y^2=25\) 右移 4、下移 1，得到 \((x-4)^2+(y+1)^2=25\)。

例3（三角）：\(y=\sin x\) 做 \(x\) 方向壓縮 2 倍，再上移 1，得到 \(y=\sin(2x)+1\)。

例4（指數）：\(y=2^x\) 左移 1，再做 \(y\) 方向放大 3 倍，得到 \(y=3\cdot 2^{x+1}\)。

例5（對數）：\(y=\log_2 x\) 右移 5，得到 \(y=\log_2(x-5)\)，定義域變 \(x>5\)。

七、分層練習（基礎/進階/挑戰）

基礎：把 \(y=x^2\) 上移 4，寫出新式。

進階：把 \(y=\cos x\) 右移 \(\frac{\pi}{3}\) 且 \(x\) 方向伸長 2 倍，寫出新式。

挑戰：已知 \(y=f(x)\) 變成 \(y'=-2f\!\left(\frac{x'+1}{3}\right)+5\)，請還原幾何操作順序。

自我檢查：每一題都要先寫 \((x',y')\) 與 \((x,y)\) 關係，再寫方程式，最後檢查定義域是否改變。
