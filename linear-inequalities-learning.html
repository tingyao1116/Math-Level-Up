國一・5-1 一元一次不等式

一元一次不等式：先讀範圍，再記負號要反向

不等式不是在找「唯一答案」，而是在找數線上的一段範圍。加、減和方程式一樣；只有在兩邊同乘或同除負數時，<、>、≤、≥ 必須反向。本頁把中文敘述、數線、合併範圍和常見應用一起整理。

1. 中文轉符號2. 數線範圍3. 負數反向4. 合併範圍5. 例題6. 自我檢查

1. 先把中文讀成不等號

先抓關鍵字：有「等於」的意思嗎？有的話就選 ≤ 或 ≥。

符號常見中文先想成
x > a大於、超過、逾比 a 還大，不含 a
x < a小於、不足、未滿比 a 還小，不含 a
x ≥ a不小於、以上、至少、達到／滿大於或等於 a，包含 a
x ≤ a不大於、以下、至多、不超過小於或等於 a，包含 a
一句口訣：「超過、未滿」沒有等號；「至少、至多、以上、以下、不超過」都要把等號算進去。
最容易混淆

「介於／之間」先看端點有沒有被包含

「x 在 2 與 5 之間」：\(2<x<5\)

若題目說「介於 2 與 5 之間，含端點」，或「不小於 2 且不大於 5」，才寫成 \(2\le x\le5\)。

常見錯誤：把「不超過 10」寫成 x < 10。剛好 10 也沒有超過，所以正確是 x ≤ 10。

2. 符號要能落在數線上

數線左小右大；端點有等號畫實心，沒有等號畫空心。

數線即時觀察

改變符號與端點，看範圍怎麼走

x > 3

3 畫空心，往右取值。

看方向：x 比端點大就往右；x 比端點小就往左。先判斷方向，再判斷空心或實心。

綠色線段和箭頭表示可取的範圍；端點圓圈提醒是否包含端點。

3. 唯一不同：乘除以負數，符號要反向

加減正負數都不反向；乘除正數也不反向。反向只發生在「同乘或同除負數」。

最重要規則：負數一出現，就先找反向

!
若 \(a<b\)，兩邊同乘（或同除）負數 \(c<0\)，會變成 \(ac>bc\)。
\(2<5\quad\xrightarrow{\times(-1)}\quad -2>-5\)

原因不是硬背：負數會把數線上每個數翻到 0 的另一邊，原本右邊較大的位置會跑到左邊，因此大小順序對調。

反向開關

用同一組數觀察正負數的差別

解題固定順序

每一行只做一種等價變形

先把含 x 的項留在一邊，常數留在另一邊。
若要消掉係數，判斷要乘除的是正數還是負數。
乘除負數時，立刻把不等號反向。
用數線或代入一個數檢查範圍是否合理。
不反向

\(3x-5\le7\)

兩邊加 5：\(3x\le12\)
兩邊除以正數 3：\(x\le4\)

除以正數，方向不變。

一定反向

\(-2x+3>9\)

兩邊減 3：\(-2x>6\)
兩邊除以 −2，反向：\(x<-3\)

錯誤警報：若仍寫 x > −3，就是漏掉「除以負數要反向」。

4. 同時要符合兩個範圍時，取重疊

看到「且、同時、都要」就找共同部分；不要把兩段範圍全都保留。

兩個同方向：取較嚴格

\(x>-1\) 且 \(x\ge3\)

大於 3 的數一定也大於 −1，所以只留下較嚴格的限制。

答案：\(x\ge3\)

兩個反方向：取中間重疊

\(x>-1\) 且 \(x\le3\)

同時在 −1 的右邊、3 的左邊，範圍被夾在中間。

答案：\(-1<x\le3\)

補充：上面是「且」的合併。若題目說「或」，只要符合其中一個條件即可，要取兩段範圍的聯集，不能直接套「取重疊」。

5. 可直接板書的例題

先翻中文或整理式子，再決定是否需要反向。

基礎・中文轉換

活動參加人數至少 25 人才成團

基礎

設參加人數為 x。因為「至少」包含剛好 25 人，所以：

\(x\ge25\)

檢查：x = 25 時確實成團；若寫 x > 25，會錯把剛好 25 人排除。

進階・負數反向

解 \(-3(x-2)\ge12\)

進階
先看係數：\(-3\) 是負數，因此最後除以 −3 時一定要反向。
兩邊除以 −3：\(x-2\le-4\)
兩邊加 2：\(x\le-2\)

最常犯錯：把第二行寫成 x − 2 ≥ −4。請在除以負數的那一行就反向，不要等到最後才想起來。

應用・至多與整數

每張票 180 元，帶 1200 元，至多可買幾張？

挑戰

設買 x 張票。總價不超過 1200 元：

列式：\(180x\le1200\)
兩邊除以正數 180：\(x\le\frac{20}{3}\)
x 是張數，只能是整數，因此最多買 6 張。

生活題提醒：不等式解是範圍；題目若是人數、張數、房間數，最後還要回到符合情境的整數。

常見應用・先找限制

門票、投票、火車與分房：關鍵字決定不等號

  • 門票打折：先算折後單價；「總費用不超過預算」寫成「折後單價 × 張數 ≤ 預算」。
  • 投票：「贊成票超過半數」是贊成票 > 總票數的一半；「至少三分之二同意」則要用 ≥。
  • 火車穿越隧道：完全通過的距離＝火車長＋隧道長；若時間至多 t 秒，就用「距離 ≤ 速度 × t」。
  • 分配房間：每間至多住 6 人，n 人至少需要 r 間時，\(6r\ge n\)；最後的房間數要往上取整數。
幾何限制・先寫合理範圍

等腰三角形的角度不等式

設底角為 x°、頂角為 y°，除了 \(2x+y=180\)，還要先知道：

\(0<x<90,\qquad 0<y<180\)

底角若到 90°，兩個底角已經合計 180°，就沒有正的頂角；所以 x 必須小於 90。這是「式子解得出來」之外，幾何情境還必須符合的範圍。

6. 自我檢查：先想，再按答案

答錯可重新選；答對後才會開啟下一題，並顯示關鍵理由。

先選一個答案，再按「檢查我的答案」。
每題三問
  1. 中文有沒有「含等號」？
  2. 這一步是否乘除負數？
  3. 答案在數線哪一側？端點空心或實心？
考前最後看

「移項」不是反向的原因。真正需要反向，是你把不等式兩邊同乘或同除一個負數。

老師投影建議：先用第 1 節讓學生把「不超過／至少」舉牌選符號；第 2 節由學生說出端點的空實與方向；再用第 3 節的 2 < 5 同乘負數，先看數線翻轉的理由，再做含負係數的題目。這樣「反向」就不只是背誦。
