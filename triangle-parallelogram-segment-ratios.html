平面幾何・比例與分點

平行四邊形比例

這一頁只處理平行四邊形：把邊上的分點、對角線交點與截線交點，整理成能直接計算的比例。先讀圖上的位置，再把同一直線上的點寫成連比。

先備工具 題型一：截線與對角線 題型二：三段連比 進階：二截線 自我檢查
先把圖形「壓平」來看

平行四邊形可以斜，但比例不會變

把平行四邊形沿著平行方向剪切成矩形，不會改變共線、平行、交點，也不會改變同一直線上的分段比。因此圖形再斜，都可以用兩個方向來記位置。

基本事實

對角線交點是兩條對角線的中點

若 AC 與 BD 交於 E，先寫：

AE : EC = BE : ED = 1 : 1

這是後面追截線比例的第一個支點；但要注意，其他直線上的交點不會自動是中點。

位置語言

用兩個邊向量描述任一點

以 B 為起點，把 BA 與 BC 當作兩個方向。落在對角線 AC 上的點 G 一定可寫成：

BG = x·BA + y·BC，且 x + y = 1

所以只要知道 x:y，就同時知道：

BG 的向量係數 x : y AG : GC = y : x
老師可先問：「G 靠近 A 還是靠近 C？」學生先用圖形判斷 x,y 的大小，再做分式計算，比較不會把順序倒過來。
題型一・參考截圖 1

兩邊分點的連線，和對角線交在哪裡？

在平行四邊形 ABCD 中，P 在 AB 上、Q 在 CD 上；連結 PQ 與對角線 AC 交於 G。本題型同時練習向量係數和 AG:GC。

可調整・也可隨機出題

從邊比求 BG = x·BA + y·BC

核心整理

直接可用的比例式

令 AP:PB=a:b、CQ:QD=c:d。把 G 寫成 BG=x·BA+y·BC，則：

x : y = c(a+b) : a(c+d)

因為 G 在 AC 上，x+y=1；所以再把上式除以兩項總和，就能得到 x,y。

同一題還能問：AG:GC = y:x。向量係數的順序和對角線分段比剛好相反，這是最常見的失分點。
截圖數值示範

AP:PB = 1:3，CQ:QD = 2:5

① 先算係數連比：x:y = 2(1+3):1(2+5)=8:7。
② 係數和為 1：x=8/15，y=7/15。
③ 寫回向量：BG = 8/15 BA + 7/15 BC。
④ 對角線分段：AG:GC = 7:8。
題型二・參考截圖 2

把 B、E、F、D 排在同一直線上，改寫成三段連比

這是很適合做成 x:y:z 的題型：先確認點的順序是 B—E—F—D，再把 BE、EF、FD 放到同一條線上比較。

連比題型產生器

求 BE : EF : FD = x : y : z

最重要的翻譯

先把文字式改成真正的比

截圖的條件 2CG = 3DG 不是 CG:GD=2:3，而是：

CG : GD = 3 : 2

一般寫成 CG:GD=m:n。在圖中，ABCG 是平行四邊形，C、G、D 共線；直線 BD 分別與 AC、AG 相交於 E、F。

常見錯誤：忘記把 E、F 排到同一條 BD 上。圖中順序是 B—E—F—D，因此中間段必須寫 EF，不能直接把 BF 當答案的一段。
三段連比公式

從 CG:GD=m:n 直接得到

BE : EF : FD = m(m+n) : m² : n(2m+n)

若 CG:GD=3:2，便有：

BE : EF : FD = 3×5 : 3² : 2×8 = 15 : 9 : 16

所以題目若改問 DF:BE，答案就是 16:15；若給 BD=40，三段長度依序就是 15、9、16。

進階・復原二截線題型

兩條截線交於 P：先辨認「同向」還是「交錯」

兩條截線若同時截同一組平行邊，就有相同的分段比；若一條截上下邊、另一條截左右邊，兩條線的分段比要分別計算。兩類題型都能再用邊長與夾角求中間分段的實際長度。

同向進階題

兩條線同時截左右邊，或同時截上下邊

同向的判準不是斜率看起來像不像，而是兩條線是否碰到同一組對邊。

需要計算實際長度時

設定平行四邊形的兩鄰邊與夾角

比例與圖形的斜度無關；但若要知道 EP、PF、GP、PH 的實際長度，就需要這三個尺寸。變更尺寸不會揭示答案。

同向的結論

兩線都截同一組對邊

EP : PF = GP : PH

可同時截 AD、BC，也可同時截 AB、DC。把圖形剪切成矩形來看，兩線被交點切開的比例相同。

交錯的提醒

一條左右、一條上下

EP : PF 與 GP : PH 要分開求

不要因為兩條線都在平行四邊形內就套用同向結論。正確順序是：先辨認每一條線碰到哪一組平行邊，再寫交點的分段比。

原本的二截線進階題

二截線的分段比：同方向與不同方向

先判斷兩條線分別截到哪一組平行邊。這裡保留原本的兩個題型與四種隨機出題層級；輸入改變時，答案會重新收起來。

課堂收束與自我檢查

平行四邊形比例題，先做這三件事

①

標出共線順序

像 B—E—F—D 必須先寫清楚。連比中的三段是相鄰的，不可跳過中間點。

②

確認比的方向

2CG=3DG 要先改成 CG:GD=3:2；向量中的 BA 也不能偷偷換成 AB。

③

最後才代總長

先得到最簡整數連比，再把 BD 依比例分配。這樣題目改問任兩段之比或實際長度都能處理。

上課建議：先投影題型二，只給 CG:GD=3:2，要求學生在圖上用顏色標出 B、E、F、D 的順序。確認連比後，再引出公式；學生會更清楚為何答案是三段而非兩段。

平行四邊形比例：先讀位置，再寫比例；先排順序，再算連比。
