先用座標格看見「兩點決定一直線」，再把同一條線換成不同方程式。本頁可直接作圖、拖曳兩點、查看轉換結果，也能處理高一常見的平行、垂直、投影、角平分線與直線系。

先抓住一件事：方程式的寫法可以不同，但只要描述的是同一批座標點，圖形就是同一條直線。遇到鉛直線 \(x=\text{常數}\) 時，斜率不存在；此時不要硬套斜截式或點斜式。

選擇已知條件

兩點 P、Q

若 x₁ = x₂，答案是鉛直線 x = x₁，不可除以 x₂ − x₁。

斜截式 \(y=mx+k\)

只能畫非鉛直線。m 表示 x 每增加 1，y 改變多少。

一般式 \(Ax+By+C=0\)

A、B 不可同時為 0；法向量可直接讀成 \(\vec n=(A,B)\)。

點斜式 \(y-y_0=m(x-x_0)\)

有一點與非鉛直方向時最省事；鉛直線請改用一般式或參數式。

參數式 \((x,y)=(x_0,y_0)+t(u,v)\)

(u, v) 是方向量，不可同時為 0；它可自然處理鉛直線，例如 (0, 1)。

截距式 \(\dfrac{x}{p}+\dfrac{y}{q}=1\)

必要條件：p、q 都不為 0；它們分別是與 x 軸、y 軸的截距，不是一般式的 A、B。

國中版：先看圖，再寫式

兩點求直線方程式

在座標平面上，兩個不同的點只會決定一條直線。國中最重要的任務是把「圖上的走法」變成 \(y=mx+k\)：先讀斜率 \(m\)，再找 \(y\) 截距 \(k\)。

1

先確認兩點不同

把 P(x₁, y₁)、Q(x₂, y₂) 標在座標格。若兩點重合，無法決定唯一一條直線。

2

算「上升 ÷ 水平」

非鉛直線的斜率是 \(m=\dfrac{y_2-y_1}{x_2-x_1}\)。\(x\) 向右走多少，\(y\) 就改變多少。

3

代一點求截距

先寫 \(y=mx+k\)，再把其中一個點代入求 \(k\)；最後用另一點驗算。

例題：通過 P(−2, 1)、Q(4, 4) 的直線

  1. 斜率：\(m=\dfrac{4-1}{4-(-2)}=\dfrac36=\dfrac12\)。
  2. 代入 \(P(-2,1)\)：\(1=\dfrac12(-2)+k\)，所以 \(k=2\)。
  3. 方程式：\(y=\dfrac12x+2\)。為了去分母，也可寫成 \(x-2y+4=0\)。
  4. 驗算 \(Q\)：\(4=\dfrac12\times4+2\)，成立。

水平線

兩點 y 座標相同，斜率 m = 0。

\(y=c\)，例如通過 \((-3,2)\)、\((5,2)\) 是 \(y=2\)。

鉛直線

兩點 x 座標相同，x 的改變量是 0，斜率不存在。

\(x=c\)，例如通過 \((3,-1)\)、\((3,4)\) 是 \(x=3\)。

怎麼由方程式畫線？

可令 x = 0 找 y 截距，再令 y = 0 找 x 截距；或直接代兩個好算的 x 值，得到兩點後連線。

補充：斜角與斜率的圖像直覺

取直線向右前進的方向，和 \(x\) 軸正向的夾角稱為斜角 \(\alpha\)，通常取 \(-\dfrac\pi2<\alpha\le\dfrac\pi2\)。非鉛直線有 \(m=\tan\alpha\)：

  • m > 0：向右上升；m = 0：水平線；m < 0：向右下降。
  • 鉛直線的斜角可看成 α = π/2，但 tan α 不存在，所以斜率不存在。
  • 不要只看線「很陡」。斜率比較的是 單位水平改變量；可在上方拖曳兩點，觀察「右 2、上 1」與「右 6、上 3」斜率其實相同。

國中最常犯的錯

  • 分子、分母的相減順序不同：要嘛都用「第 2 點減第 1 點」，要嘛都反過來；不能 y₂−y₁ 搭配 x₁−x₂。
  • 把鉛直線寫成 y = mx + k：它沒有有限斜率，答案應是 x = 常數。
  • 只代一點、不驗算：代回另一點能立刻抓出截距正負號算錯。
  • 把斜率看成 y/x：斜率是兩點之間的「改變量比」，不是任意一點的 y ÷ x。
高中版：依已知條件選最快寫法

同一條直線的七個表示法

不要背成一串孤立公式。先問「題目給我什麼？」：給兩點就用二點式；給一點與斜率就用點斜式；給方向量就用參數式；給法向量就用一般式。最後需要時再化成題目指定的形式。

給兩點

二點式

\[\frac{y-y_1}{x-x_1}=\frac{y_2-y_1}{x_2-x_1}\]

條件是 \(x_1\ne x_2\)。更穩健的交叉相乘寫法為 \((x_2-x_1)(y-y_1)=(y_2-y_1)(x-x_1)\)，可避免太早除法；若 \(x_1=x_2\)，直接寫 \(x=x_1\)。非鉛直線另有 \(m=\tan\alpha\)。

給一點、斜率

點斜式

\[y-y_0=m(x-x_0)\]

最適合「通過 \(P(x_0,y_0)\)，斜率為 \(m\)」。它是從斜率定義直接來的；鉛直線沒有 \(m\)，改寫 \(x=x_0\)。

給斜率、y 截距

斜截式

\[y=mx+k\]

\(m\) 是斜率，\(k\) 是 \(y\) 截距（與 \(y\) 軸交於 \((0,k)\)）。看圖最快，但仍不能表示鉛直線。

給法向量

一般式

\[Ax+By+C=0\]

\(A\)、\(B\) 不可同時為 \(0\)，法向量是 \(\vec n=(A,B)\)；一個方向量可取 \(\vec d=(B,-A)\)。它能自然表示所有直線，包括 \(x=c\)。

給一點、方向量

參數式

\[(x,y)=(x_0,y_0)+t(u,v),\quad t\in\mathbb R\]

\((u,v)\) 是非零方向量。展開成 \(x=x_0+tu,\quad y=y_0+tv\)；若 \((u,v)=(0,1)\)，就是鉛直線。

判斷共線

三點共線（不必求方程式）

\[\frac{y_2-y_1}{x_2-x_1}=\frac{y_3-y_1}{x_3-x_1}\]

在分母不為 \(0\) 時比較斜率即可。含鉛直情形，改用更通用的面積／叉積判斷：\((x_2-x_1)(y_3-y_1)-(y_2-y_1)(x_3-x_1)=0\)。

給兩軸截距

截距式

\[\frac{x}{p}+\frac{y}{q}=1\]

\(p\) 是 \(x\) 截距、\(q\) 是 \(y\) 截距，交點為 \((p,0)\)、\((0,q)\)。必要條件 \(p\)、\(q\) 都不為 \(0\)；直線過原點或平行任一座標軸時不可使用。

例題：通過 P(1, −2)，方向量為 (3, 2)

  1. 先寫參數式：\((x,y)=(1,-2)+t(3,2)\)。
  2. 方向量 \((3,2)\) 對應斜率 \(m=\dfrac23\)，所以點斜式為 \(y+2=\dfrac23(x-1)\)。
  3. 方向量 \((3,2)\) 的一個法向量是 \((2,-3)\)，故一般式為 \(2(x-1)-3(y+2)=0\)，即 \(2x-3y-8=0\)。
  4. 由一般式化成斜截式：\(y=\dfrac23x-\dfrac83\)。

高中常見混淆

  • 一般式的 B 與截距式的 q 不同：為避免字母撞名，本頁以 p、q 表示兩軸截距。
  • 方向量與法向量搞反：方向量沿著線走；法向量垂直於線。對一般式 Ax+By+C=0，(A,B) 是法向量，不是方向量。
  • 把斜率乘積 −1 當萬用垂直判斷：鉛直線沒有斜率。用向量內積或一般式的 \(A_1A_2+B_1B_2=0\) 更安全。
  • 截距式分母可為 0：p=0 或 q=0 時式子本身沒有意義，應改用其他形式。
高中進階：把目前直線當作 L

平行、垂直、投影與直線系互動工具

先在上方作圖器畫出目前直線 L，再在這裡輸入點或兩條線。進階結果會直接疊在同一張座標平面；按上方任一「畫線」按鈕即可回到單一直線模式。

給點 P，處理目前直線 L

若 L: Ax+By+C=0，過 P 的平行線保留同一法向量 (A,B)；垂線可取法向量 (B, −A)。

兩點 P、Q 的中垂線

中垂線通過 PQ 的中點，且垂直於 PQ；在線上的點到 P、Q 等距。

兩條直線 L₁、L₂

角平分線與本工具的直線系先處理相交兩直線。L₁、L₂ 平行時沒有共同交點，不能解讀成「過共同點的一束線」。

平行與垂直

對 Lᵢ: Aᵢx+Bᵢy+Cᵢ=0：

\(A_1B_2-A_2B_1=0\) 判斷平行；\(A_1A_2+B_1B_2=0\) 判斷垂直。

這兩個判斷含鉛直線，不必冒險使用斜率。

投影點、對稱點、距離

令 \(s=\dfrac{Ax_0+By_0+C}{A^2+B^2}\)。

投影 \(H=\)\((x_0-As,y_0-Bs)\)；對稱點 \(P'=\)\((x_0-2As,y_0-2Bs)\)；距離 \(d=\dfrac{\lvert Ax_0+By_0+C\rvert}{\sqrt{A^2+B^2}}\)。

角平分線

兩相交線 L₁=0、L₂=0 的角平分線為：

\[\frac{L_1}{\sqrt{A_1^2+B_1^2}}=\pm\frac{L_2}{\sqrt{A_2^2+B_2^2}}\]

一定要先除以法向量長度；直接寫 L₁=±L₂ 只在兩式法向量長度恰好相同時才對。

直線系

若 \(L_1\)、\(L_2\) 相交，完整寫法是 \(\lambda L_1+\mu L_2=0\)，其中 \((\lambda,\mu)\) 不可同時為 \(0\)；它表示所有通過共同交點的直線。

常見單參數寫法 \(L_1+tL_2=0\) 少了 \(L_2\) 本身，需另外補上 \(L_2\)。

二元一次聯立：把「解況」看成兩條直線的位置關係

若以本頁的一般式寫成 \(L_1:A_1x+B_1y+C_1=0\)、\(L_2:A_2x+B_2y+C_2=0\)，係數比例可直接告訴我們解的數量。可按上方「判斷聯立解況」把結果畫出來。

聯立解況圖形係數判斷（分母存在時的比例寫法）
唯一解兩線相交於一點\(\dfrac{A_1}{A_2}\ne\dfrac{B_1}{B_2}\)；更通用地說，\(A_1B_2-A_2B_1\ne0\)。
無限多解兩線重合\(\dfrac{A_1}{A_2}=\dfrac{B_1}{B_2}=\dfrac{C_1}{C_2}\)。
無解兩線平行且不同\(\dfrac{A_1}{A_2}=\dfrac{B_1}{B_2}\ne\dfrac{C_1}{C_2}\)。

若教材把式子寫成 \(ax+by=c\)，常數項只要整體移到左邊即可；比例結論不變。用行列式 \(A_1B_2-A_2B_1\) 判斷是否相交，能避開「某係數為 \(0\) 時不能相除」的問題。

進階例題：L: 2x − y − 3 = 0，P(1, 4)

  1. 過 \(P\) 的平行線：保留法向量 \((2,-1)\)，得 \(2x-y+2=0\)。
  2. 過 \(P\) 的垂線：可取法向量 \((-1,-2)\)，得 \(x+2y-9=0\)。
  3. \(s=\dfrac{2\times1-4-3}{2^2+(-1)^2}=-1\)，所以投影點 \(H=(3,3)\)，對稱點 \(P'=(5,2)\)，距離為 \(\sqrt5\)。
可直接課堂使用

分層練習與自我檢查

基礎：兩點與斜截式

求通過 (−1, 3)、(3, 5) 的直線。

核對

\(m=\dfrac{5-3}{3-(-1)}=\dfrac12\)；代入得 \(y=\dfrac12x+\dfrac72\)，一般式為 \(x-2y+7=0\)。

進階：三點是否共線？

A(−2, 1)、B(1, 3)、C(4, 5) 是否共線？請不要先求方程式。

核對

AB 斜率=(3−1)/(1−(−2))=2/3；AC 斜率=(5−1)/(4−(−2))=2/3，因此三點共線。

挑戰：角平分線與直線系

L₁:x+y−2=0、L₂:x−y=0。求兩角平分線，並寫通過共同點的直線系。

核對

兩法向量長度皆為 \(\sqrt2\)，因此 \(L_1=\pm L_2\)，得 \(x=1\)、\(y=1\)。直線系為 \(\lambda(x+y-2)+\mu(x-y)=0\)，\((\lambda,\mu)\ne(0,0)\)。

老師上課建議：先讓學生用上方兩點模式拖曳紅點，口頭描述「往右 2、往上 1」；再切到點斜式、一般式與參數式，問學生：哪個量是方向？哪個量垂直於線？最後才用進階工具把向量觀點連到投影與距離。
