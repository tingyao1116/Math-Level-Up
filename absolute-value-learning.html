國中到高中・數與式、數線與最值

絕對值：把「距離」讀懂，規則就不必硬背

絕對值的結果不是「隨便取正」，而是數線上的距離。從 |x|、|x-y| 到等式與不等式，都能用「離中心多遠」解釋；最後再看為什麼距離總和找中位數、平方總和找平均數。

1. 距離意思 2. 去絕對值 3. 不等式與端點 4. 三角不等式 5. 最小值 6. 自我檢查

1. 絕對值是距離：先有圖像，再記規則

請先問學生：「從 0 走到 −5，要走幾格？」

核心概念

|x|：x 到 0 的距離

|x| = x（x ≥ 0）；|x| = −x（x < 0）

|5|=5，|−5|=5。負數放進絕對值後不是「負號被吃掉」，而是距離本來就不會是負的。

常見錯誤：|x|=x 並非對所有 x 都成立；當 x 是負數時，必須變成 −x 才會得到正距離。
兩點距離

|x-y|：x 與 y 的距離

兩點距離 = |x−y| = |y−x|

相減時先算出「有向差」，再取它的距離。例如 x=−3、y=4 時，|−3−4|=|−7|=7。

課堂口訣：「絕對值看距離；距離一定非負。」先讓學生在數線上數格，再寫算式。

2. 去絕對值：等式要分成左右兩種情形

距離等於固定長度，通常會找到中心左右各一個位置。

等式規則

先判斷右邊，再拆成兩條式子

|A|=b，b>0 ⇒ A=b 或 A=−b
  • b=0：只有 A=0 一種。
  • b<0：無解，因為距離不可能小於 0。
常見錯誤：只寫 A=b，漏掉 A=−b；這等於只找中心的一側。
例題・基礎

解 |2x−3|=5

距離為 5，所以內部可為 5 或 −5。
2x−3=5 或 2x−3=−5。
得到 x=4 或 x=−1。

檢查：代回後分別為 |8−3|=5、|−2−3|=5，兩個都成立。

3. 絕對值不等式：小於在中間，大於在兩側

把 |x-a| 想成「x 離中心 a 有多遠」。

距離小於

在中心附近：夾在中間

|x−a| < r ⇔ a−r < x < a+r

離 a 的距離小於 r，代表不能超過左、右兩個界線，所以解集中在中間。

含等號時：|x−a|≤r ⇔ a−r≤x≤a+r。

距離大於

離開中心：跑到兩側

|x−a| > r ⇔ x < a−r 或 x > a+r

距離大於 r，表示中間那段都太近；合格的位置在左外側或右外側。

含等號時：|x−a|≥r ⇔ x≤a−r 或 x≥a+r。

空心點：不包含端點；實心點：包含端點。中間是一段，兩側是兩段。

反向回推的固定公式（端點不含）：
p < x < q　⇔　|x−中點| < 半距

其中 中點=(p+q)/2，半距=(q−p)/2。也就是先找範圍的中點，再找中點到端點的距離。

例如 −1<x<7 的中點是 3、半距是 4，因此回推為 |x−3|<4。若端點包含，兩邊的不等號一起改成 ≤；兩側範圍則回推成 |x−a|>r 或 |x−a|≥r。

例題・中間

解 |x−2|<4

把「距離小於 4」翻成 −4<x−2<4。
三邊同加 2：−2<x<6。
數線上畫 −2、6 的空心點，塗中間。
例題・兩側

解 |2x+1|≥5

距離至少 5：2x+1≤−5 或 2x+1≥5。
分別解得 x≤−3 或 x≥2。
數線畫 −3、2 的實心點，塗兩側；中間不塗。

4. 三角不等式：繞路不會比直走更短

在數線上，這其實是「從 x 先走到 y，再走到 z」。

距離的基本性質
|x−z| ≤ |x−y| + |y−z|

直接從 x 到 z 的距離，不會超過先經過 y 的總路程。當 y 剛好在 x、z 中間時，走法沒有繞路，等號成立。

0

紫色的路徑是 x→y→z；藍色是直接 x→z。

易混淆點：不等號是「≤」，不是永遠等於。若 y 跑到 x、z 以外，例如先從 −5 走到 7 再回到 4，就多走了回頭路。

5. 連續多個絕對值的最小值：找中位數；平方和：找平均數

同一組資料，改變「誤差的計算方式」，最佳位置就會不同。

資料點放在數線上；移動 t，看兩種「總距離」如何改變。

要最小化的量最佳的 t為什麼
Σ|t−aᵢ|中位數（偶數個資料時，中間兩數之間都可以）往左或右移動時，左右兩邊的距離增減在中位數處取得平衡。
Σ(t−aᵢ)²平均數偏得越遠，平方的懲罰越重；平均數會被極端值拉動。
教學連結：若要選「使所有人的走路總距離最短」的集合地點，用中位數；若要選「使偏差平方總和最小」的代表值，用平均數。這也是統計裡兩者角色不同的原因。
挑戰推理：把資料由小到大排好。對 Σ|t−aᵢ| 而言，若 t 在中位數左邊，往右移通常會讓較多距離變短；在中位數右邊則相反。所以最低點落在中位數位置（偶數筆時是一整段）。
