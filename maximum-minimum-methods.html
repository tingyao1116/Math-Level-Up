函數的最大、最小值：方法總整理

求最值不是看到題目就急著微分。先看定義域與式子的結構，再挑能保留「等號何時成立」的方法。這一頁把高中常見的代數、三角、指數對數與微分策略放在同一張地圖裡。

先看範圍 再選方法 最後驗等號與端點

先選工具：題目長相決定解法

一題可能有不只一種解法；下表的目的不是背招式，而是先辨認「哪個結構最明顯」。

1

先畫界線

分母不能為 0、根號內 ≥ 0、真數 > 0；有給區間時端點也要保留。

2

平方型？

看到二次式或可設換元，優先想配方法，但別忘了新變數的範圍。

3

正數和、積、比？

有正數條件與對稱結構，試算幾不等式；有線性組合或平方和，試柯西不等式。

4

參數 y 的可取值？

把 y = f(x) 改寫成 x 的方程式，問「何時有實數解」：用判別式 Δ ≥ 0。

5

sin、cos 線性組合？

A sin θ + B cos θ 可做三角疊合；若是 sin²、cos²，先設 t 並附上 −1 ≤ t ≤ 1。

6

指數、對數藏在式內？

設 t = ax > 0 或 t = logax，再用配方法、不等式或範圍判斷。

7

光滑函數、區間已給？

前面沒有漂亮結構，或題目問局部極值，就用微分：臨界點、不可微點、端點一起比較。

✓

收尾一定問

上下界真的取到嗎？等號條件是否符合定義域？是局部極值，還是全域最大／最小值？

零、所有方法的起點：先把「可取範圍」寫出來

很多最值題失分，不是方法不會，而是把不能取的值拿去代入，或把「理想的平方最小值」誤認成一定取得到。下列範圍要成為看到就會反應的基本工具。

倒數與正負

倒數和要先分正、負

x > 0 ⇒ x + 1/x ≥ 2；等號在 x = 1。
x < 0 ⇒ x + 1/x ≤ −2；等號在 x = −1。

不是所有 x ≠ 0 都有 x + 1/x ≥ 2。負數時方向要改。

指數、對數

換元前先附條件

ax > 0（a > 0, a ≠ 1），而且值域是正數。

logax 的定義域為 x > 0，值域是所有實數。若是 logag(x)，必須先寫 g(x) > 0。

三角函數

角度範圍會改變答案

任意實數 θ：−1 ≤ sin θ ≤ 1、−1 ≤ cos θ ≤ 1。

若 0° ≤ θ ≤ 90°，則 sin θ, cos θ ∈ [0,1]，tan θ ∈ [0, +∞)。

若 0° ≤ θ ≤ 180°，則 sin θ ∈ [0,1]；cos 的範圍仍為 [−1,1]。

先問一句：題目的變數是任意實數？正數？還是在指定區間？同一個式子因為範圍不同，最大、最小值可能完全不同。

方法目錄

1. 配方法 2. 算幾不等式 3. 柯西不等式 4. 判別式 Δ ≥ 0 5. 三角疊合 6. 三角配方＋範圍 7. 指數對數換元配方 8. 微分求極值
1

基本方法：配方法

看到二次式 ax² + bx + c，把它改寫成「平方項＋常數」。平方項 ≥ 0，就能讀出最值。

適用訊號

二次式很完整

x²、x、常數都出現，且變數 x 的範圍沒有太多限制。

判讀規則

看平方項前係數

若 a > 0，有最小值；若 a < 0，有最大值。因為 (x−h)² ≥ 0。

必要檢查

頂點真的可取嗎？

若題目限制 x 在一段區間，頂點不在區間內時，要改比較端點。

例題：求 f(x) = 2x² − 8x + 5 的最小值

  1. f(x) = 2(x² − 4x) + 5 = 2[(x−2)² − 4] + 5。
  2. = 2(x−2)² − 3。
  3. 因 2(x−2)² ≥ 0，所以 f(x) ≥ −3。

答案：最小值為 −3，在 x = 2 時取得。

常見錯誤

把 2(x−2)²−3 的最小值寫成 0。0 只是平方項的最小值；整個函數還有 −3。

2

正數的平衡：算術－幾何平均不等式

當兩項（或多項）是非負數，而題目同時出現和、積、倒數時，算幾不等式能把「兩項要一樣大」轉成最值。

兩項公式：a + b ≥ 2√(ab)（a, b ≥ 0）；等號成立當且僅當 a = b。

例題：x > 0，求 x + 9/x 的最小值

  1. 因為 x > 0，所以 x 與 9/x 都是正數，可以用算幾不等式。
  2. x + 9/x ≥ 2√(x·9/x) = 6。
  3. 等號條件：x = 9/x，所以 x = 3，確實符合 x > 0。

答案：最小值為 6，在 x = 3 時取得。

正數版本

x > 0 ⇒ x + 1/x ≥ 2

負數版本

x < 0 時令 u = −x > 0，可得 x + 1/x ≤ −2。

常見錯誤

沒有正數／非負數條件就直接套公式。遇到負數時，先分情況或改設正數，再開始不等式。

3

平方和與線性組合：柯西不等式

若題目有「平方和固定」卻要求線性式的最大值，或「和固定」卻要求平方和的最小值，柯西－施瓦茨不等式很自然。

常用型：(a²+b²)(x²+y²) ≥ (ax+by)²。
等價觀點：固定 x²+y² 時，ax+by 的絕對值不會超過「兩個長度的乘積」。

例題：若 x² + y² = 1，求 3x + 4y 的最大值

  1. 套用柯西：(3²+4²)(x²+y²) ≥ (3x+4y)²。
  2. 25·1 ≥ (3x+4y)²，故 −5 ≤ 3x+4y ≤ 5。
  3. 最大值為 5。等號需兩組數成比例，取 (x,y) = (3/5,4/5) 即可。

圖像直覺：x²+y²=1 是單位圓；直線 3x+4y=k 往外推到剛好和圓相切時，k 就是最大值。

另一個常用結論

由 (1²+1²)(x²+y²) ≥ (x+y)² 得 x²+y² ≥ (x+y)²/2。例如 x+y=10 時，x²+y² ≥ 50，等號在 x=y=5。

4

萬用反推法：利用「有解」的判別式 Δ ≥ 0

題目問 y=f(x) 的值域，而直接配方不順時，把 y 視為參數，改問「給定 y，是否存在實數 x？」。

核心翻譯：y 在值域中 ⇔ 方程式 y = f(x) 對 x 有實數解。
若整理為二次方程式 Ax²+Bx+C=0，需 Δ=B²−4AC ≥ 0。

例題：求 y = x/(x²+1) 的值域

  1. 分母 x²+1 > 0，所有實數 x 都可用。移項：yx² − x + y = 0。
  2. 要有實數 x，判別式必須 Δ = (−1)² − 4(y)(y) = 1−4y² ≥ 0。
  3. 所以 4y² ≤ 1，得到 −1/2 ≤ y ≤ 1/2。

答案：值域為 [−1/2, 1/2]。端點 Δ = 0，代表直線與曲線剛好相切，因此端點可以取到。

常見錯誤

當 y 的係數可能變成 0 時，原本的「二次方程式」會退化成一次式。例如本題 y = 0 時方程變成 −x=0，仍有解；做完後要特別檢查這種退化情形。

5

三角疊合：把兩個波合成一個波

只要是 A sin θ + B cos θ，就把它寫成振幅為 √(A²+B²) 的單一 sin 或 cos。振幅就是最大絕對值。

A sin θ+B cos θ = R sin(θ+φ)，其中 R=√(A²+B²)，並取 R cos φ=A、R sin φ=B。
若 θ 可取所有實數，值域就是 [−R,R]。

例題：求 √3 sin θ + cos θ 的最大、最小值

  1. 振幅 R=√[(√3)²+1²]=2。
  2. 取 φ=30°，則 2sin(θ+30°)=√3 sin θ+cos θ。
  3. 因 −1≤sin(θ+30°)≤1，所以 −2≤√3 sin θ+cos θ≤2。

答案：最大值 2、最小值 −2。若 θ 有指定區間，要再確認 θ+φ 是否能取到讓 sin 等於 ±1 的角。

常見錯誤

只算出 R=√(A²+B²)，卻忘了題目可能限制 θ，例如 0°≤θ≤30°。此時整個 [−R,R] 未必都走得到。

6

三角配方＋範圍：設 t 後，範圍不能丟

遇到 sin²θ、cos²θ 或它們的二次式，先設 t=sinθ（或 cosθ），但 t 並非任意實數：−1≤t≤1。

例題：求 f(θ)=sin²θ−4sinθ+1 的最大、最小值

  1. 設 t=sinθ，所以 −1≤t≤1。
  2. f=t²−4t+1=(t−2)²−3。
  3. 因 −1≤t≤1，故 −3≤t−2≤−1，所以 1≤(t−2)²≤9。
  4. 因此 −2≤f≤6；在 t=1 時最小，在 t=−1 時最大。

答案：最小值為 −2（sinθ=1），最大值為 6（sinθ=−1）。

最容易錯的地方

(t−2)²−3 的頂點在 t=2，但 sinθ 不可能是 2。因此不能說最小值是 −3；要回到 t∈[−1,1]。

7

指數、對數：先換元，再配方或用不等式

指數與對數最值的關鍵是：新變數的範圍通常不是所有實數。設完 t，立刻把條件寫在旁邊。

指數配方

求 4x−6·2x+5 的最小值。

  1. 設 t=2x>0，則 4x=t²。
  2. t²−6t+5=(t−3)²−4≥−4。
  3. t=3>0 可取，所以最小值是 −4。

對數配方

求 (log2x)²−4log2x+1 的最小值。

  1. 定義域先寫 x>0；設 t=log2x，則 t 為任意實數。
  2. t²−4t+1=(t−2)²−3≥−3。
  3. t=2 對應 x=4，所以最小值為 −3。

常見錯誤

把 t=2x 當作可取 0 或負數，或忘記對數的真數條件。換元不是只換符號，也把原本的範圍一起搬過來。

8

萬用收網：微分求極值

當式子沒有明顯的配方、不等式或三角結構，微分是穩定的通法。要分清楚「局部極值」與「指定區間的全域最值」。

閉區間 [a,b] 求全域最大最小值流程：
① 找 f'(x)=0 的臨界點；② 加入 f′ 不存在但 f 有定義的點；③ 加入端點 a、b；④ 比較所有候選點的 f 值。

例題：求 f(x)=x³−3x 在 [−2,3] 的最大、最小值

  1. f′(x)=3x²−3=3(x−1)(x+1)，臨界點為 x=−1,1。
  2. 候選點是 −2,−1,1,3。
  3. 逐一代入：f(−2)=−2，f(−1)=2，f(1)=−2，f(3)=18。

答案：全域最大值為 18（x=3）；全域最小值為 −2（x=−2 或 1）。

常見錯誤

只解 f′(x)=0，忘記端點。尤其在閉區間題，真正的最大值常常就在端點。另外，若定義域是全體實數，也要先確認函數是否真的有全域最大或最小值。

課堂使用建議：把「最值」教成選工具，而不是背八招

第一節導入

先丟同一題 x+9/x，分別給 x>0 與 x<0。讓學生發現條件一換，不等號方向就不同，再建立「先看範圍」的習慣。

板書主軸

每個方法都固定寫三句：可用條件、不等式或變形、等號何時成立。學生會更容易把答案的數值與取得位置連起來。

收尾比較

安排「頂點在範圍外」與「三角角度受限」各一題。這兩類最能提醒學生：求到一個下界後，還要驗證它能不能真的取到。

最大最小值的共同語言：先找範圍，再找界；最後確認界能取到。
